## Shared cleanup and performance

- New tab/panel manifests define the workflow order explicitly; every current child is listed exactly once.
- Hardware lookup accepts editable unfinished fields outside the requested hardware operation. Size-matched hangers still require a valid loaded joist and actual dimensions. Explicit ties/brackets and Drawing Finder can be opened without a joist. Invalid Build/Preview inputs still stop modeling.
- Reopening settings after library use retains drafts, selected mode and relevant tab. Generating a clip family also retains drafts.
- Board-to-row indexing replaces repeated whole-board scans. The regular long-deck planner reuses its two stagger patterns; the regression checks exactly two pattern calculations for a layout with more than 50 rows.
- Family/type labels avoid duplicated identical names. Logs include release version and extension path; logging I/O has a best-effort fallback. Build/accessory/manager errors distinguish committed work from rollback.
- All seven indexed Simpson URLs were simplified to omit query parameters and verified with HTTP 200 HEAD responses. This is link availability evidence, not a native RFA test.
- Original Hello World and Lumber Library files retain 13 recorded hashes. No other extension, including ROBMEPTOOLS, was edited.

## Limits and next focused work

No full legacy migration is asserted: the recorded FRAMETOOLS/DECKTOOLS source paths are currently absent. No RFAs are claimed to flex correctly until tested in Revit. Boards are countable DirectShapes rather than per-board parametric families. The roof option projects a level deck above one sloped Floor; pitched framing is absent. Curves/openings/multi-facet roofs and automatic multi-zone support design remain deferred.

Stairs support one straight native run; railings use selected perimeter paths and one manual opening. They are separate accessories and must be rerun after parent deck changes. No automatic stair-derived railing opening, timber fabrication system or complete guard/stair compliance design is implemented.

Material stock estimates use first-fit decreasing lengths by compatible group; they do not optimize nesting or recover ripped widths. Fasteners, footings, bracing and unmodeled post hardware are not inferred. Beam/member capacity and connector engineering are outside the current automatic checks.

Start field testing with the user's stepped Floor and a manual breaker center, then verified framing/Simpson fit, followed by supports, accessories and quantities. See `REVIT_TEST_CHECKLIST.md` for exact settings and expected baseline counts.
